# Projects

## Kubernetes Platform Migration

Migrated a monolithic legacy stack to a containerized Kubernetes platform across 20+ services with zero downtime. Built GitOps-driven provisioning using Terraform and Argo CD, introduced Helm charts, and implemented autoscaling.

**Impact:** 75% faster deployments; uptime improved from 98.9% to 99.9%.

**Technologies:** Terraform, Kubernetes, Helm, Argo CD, AWS

---

## CI/CD Pipeline Overhaul

Replaced manual releases with multi-stage Jenkins pipelines featuring parallel testing, artifact caching, and automated rollbacks.

**Impact:** Reduced release cycles from 24 hours to 20 minutes and failed deployments by 90%.

**Technologies:** Jenkins, Docker, GitLab CI, SonarQube

---

## Observability Stack Rollout

Implemented centralized monitoring, logging, and alerting using Prometheus, Grafana, Loki, and the ELK Stack, with supporting alerting runbooks.

**Impact:** Improved MTTR by 60% and achieved full visibility across environments.

**Technologies:** Prometheus, Grafana, Loki, ELK Stack
